Gain a comprehensive understanding of ServiceNow’s Configuration Management Database (CMDB) and the Common Service Data Model (CSDM) that defines its structure. The cards below are arranged to follow a natural learning progression: start with an overview of the CMDB, then learn how to ingest data into it, understand how it is configured, explore how to govern and maintain it, and finally review the tools used to gain insight from the data.

This structure is intended to help you build context in layers. Each topic builds on the previous one so you can move from foundational concepts to practical implementation and, ultimately, to reporting and analysis. Together, these topics show how CMDB and CSDM work as a trusted source of configuration data that supports consistent service modeling, reliable reporting, and data-driven IT operations across the enterprise.
