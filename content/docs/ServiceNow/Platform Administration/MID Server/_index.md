## Overview

The Management, Instrumentation, and Discovery (MID) Server is a lightweight Java service that runs inside your network and acts as a secure bridge between your ServiceNow instance and internal systems.

MID Servers are commonly used for Discovery, Orchestration, integrations, and any use case where ServiceNow needs controlled access to on-premises or private cloud resources without exposing those systems directly to the internet.

This section focuses on practical setup and operations for MID Server administration.
