## Overview

Script Includes are reusable, server-side JavaScript classes and functions. They're commonly used to centralize business logic that's called from Business Rules, other Script Includes, or client-side scripts via GlideAjax — and, as shown here, from dynamic reference qualifiers on fields and variables.

This section covers patterns and examples for Script Includes.
