## Overview

Email Scripts are template based scripts executed when notifications are sent from ServiceNow. They format and customize email content, including query result rendering, formatted approval histories, and dynamic recipient lookup where existing notification conditions and values are insufficient. They can be used to generate complex email content based on server queries and logic, allowing for highly customized email notifications.

This section documents Email Script patterns and implementations.
